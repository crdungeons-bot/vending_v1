# Dunning Reed Vending Website

A modern Next.js website for Dunning Reed Vending, a locally owned vending machine operator serving Ventura County businesses.

## Features

- Modern 2026 design with gradient backgrounds and smooth animations
- Fully responsive layout
- SEO optimized
- Custom brand colors integrated throughout
- Sticky header with quick call-to-action
- Engaging hero section with animated background
- Feature cards with hover effects

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is designed to be deployed on [Vercel](https://vercel.com) directly from GitHub.

1. Push your code to GitHub
2. Import your repository in Vercel
3. Deploy!
